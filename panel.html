Graph

The discovery graph is the provenance map: every node is a route, resource, JS chunk, API endpoint or frame, and every edge records how it was found (dom-link, dynamic-import, sourcemap-ref, deep-scan…). Use case: pick a search hit, then trace its chain here — e.g. route /models → chunk assets/x.js → endpoint /api/models — to see exactly which file and discovery step exposed a string, and what else that file pulled in.
