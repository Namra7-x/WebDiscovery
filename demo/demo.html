DeepScope v3.12.0 Playground Demo

This demo page is built to let you see and verify all 6 reverse-engineering features firing live in DeepScope DevTools!

Feature 1 Runtime Memory Store (Redux + LocalStorage)

We loaded a simulated Redux store and auth tokens into page memory. Click "Harvest State" on DeepScope's Overview tab to extract them!

Feature 2 Client-Side Feature Flag Tampering

Normally, the API returns {"enable_admin": false, "beta_dashboard": false}. With "Tamper Feature Flags" enabled in DeepScope, it will flip to true!

Feature 3 Next.js Build Manifest (Hidden Routes)

This page defines a real Next.js self.__BUILD_MANIFEST with hidden routes (like /admin/super-secret-vault). Check DeepScope's Routes tab!

Feature 4 AST Parameter & Payload Schema

This page's JavaScript calls an uncalled billing endpoint with body keys: user, cardToken, amount, bypassPin. Check DeepScope's APIs tab!

Features 5 & 6 Source Map (.map) & GraphQL Queries

This page loads demo-app.js with a real source map and bundled GraphQL queries. Check "Export Source ZIP (2)" and "Export GraphQL (2)"!
